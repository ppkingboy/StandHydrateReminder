# 站立喝水提醒

一个原生 macOS 状态栏小应用，定时提醒站立和喝水。常驻菜单栏，按设置的时间间隔在全屏弹出提醒窗口。

## 功能

- **站立/喝水定时提醒** — 默认站立 45 分钟、喝水 30 分钟，可自定义间隔
- **全屏提醒窗口** — 置顶显示在当前屏幕中央，支持自定义按钮文字、字体、颜色
- **字体缩放** — 根据屏幕宽度自动缩放提醒窗口中的文字大小
- **开机自启** — 使用 `SMAppService`，在设置中一键开启
- **免提醒时段** — 设置静音时间段（如 22:00 – 08:00），支持跨午夜
- **RGB 调色** — 自定义提醒窗口背景颜色和字体颜色
- **统计图表** — 柱状图 + 饼图，按日/周/月/年查看，支持分析总结
- **数据清零** — 统计窗口中一键清除所有记录

## 设置

菜单栏 → 设置 → 子菜单中有 5 个独立配置窗口：

| 窗口 | 配置项 |
|------|--------|
| **基本设置** | 站立/喝水间隔、弹窗宽度、开机自启、登录项、免提醒时段、保存并重启 |
| **背景设置** | RGB 背景颜色、透明度、还原默认 |
| **字体与按钮** | 字体选择、文字背景色、字体颜色、透明度、按钮风格、还原默认 |
| **自定义动作** | 按钮文字（站立积极、喝水积极、暂缓） |
| **分析配置** | 日/周/月/年分析文案、表扬语（≥90%/≥70%/≥50%/<50%）、还原默认 |

每个配置窗口都有独立的「保存」按钮和「还原默认」按钮（分析配置仅有「保存」）。

## 运行

双击 `build/站立喝水提醒.app` 启动。菜单栏会出现「站水」。

## 重新构建

```sh
./build.sh
```

依赖：macOS 13.0+、Xcode Command Line Tools（`clang`）。

## 技术栈

- 语言：Objective-C
- 框架：AppKit、Cocoa、ServiceManagement
- UI：NSGridView、NSBox、NSColorWell、CoreGraphics 自绘图表
- 存储：NSUserDefaults
- 最小系统版本：macOS 13.0

## 开机自启

使用 Apple 的 `SMAppService.mainAppService` 登录项机制，在「基本设置」中点击「开机自启」后保存即可。如需确认，请在「系统设置 → 通用 → 登录项」中允许。

## 免提醒时段

格式 `HH:mm`，使用本机时间判断。支持跨午夜（如 `22:00` – `08:00`）。

测试提醒不受免提醒时段限制，方便确认窗口效果。
